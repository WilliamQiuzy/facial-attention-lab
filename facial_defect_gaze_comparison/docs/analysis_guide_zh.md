# 两个独立 500 人队列应该怎么比较

## 先说结论

你们现在不是“同一批人用两台设备测两次”，而是：

- Prolific/Webcam：500 人；
- Mayo/专业设备：另外 500 人；
- 两组参与者完全不同。

因此不能计算“同一个人的两台设备一致性”，也不能用 Bland–Altman 图说明设备可互换。真正可以回答的是：

> 在相同刺激和任务协议下，两套完整采集流程得到的群体数据分布，是否对某个明确用途足够接近？

这里的“完整采集流程”同时包含设备、算法、招募来源、家庭/实验室环境和参与者构成。500 对 500 会让估计更精确，但不会自动消除这些混杂。

## 不要问一个模糊的“是不是同一个域”

建议拆成两个域：

1. **技术采集域**：精度、抖动、丢失率、有效试次比例是否能区分来源？
2. **注意力结果域**：看眼睛、鼻子、嘴巴的分布和整张热力图是否能区分来源？

这两个答案可以不同。Webcam 数据在技术上可能明显更容易识别，但 500 人聚合后的脸部注意力分布仍可能与专业设备足够接近。这个结论比一个综合分数更有用。

## 四步主分析

### 第一步：先检查两组是否可比

检查项目：

- 是否看完全相同、版本一致的脸部图片；
- 指令和展示时长是否相同；
- 图片在屏幕上的裁剪、缩放和坐标转换是否相同；
- QC 和排除规则是否相同；
- 年龄、眼镜、以往眼动经验是否严重失衡；
- 屏幕大小、光线等真实采集环境有多大差别。

主要指标是标准化均差 SMD。它把不同单位的变量放到同一尺度。`|SMD| < 0.10` 只能作为检查提示，不能证明两组已随机化或没有混杂。

对应图：`01_covariate_balance.png`。

### 第二步：技术质量不要只做普通显著性检验

主要看四项：

| 指标 | 为什么重要 | 怎么算 |
|---|---|---|
| 校准准确度 | 热图可以很平滑，但整体位置可能偏掉 | 注视位置到已知校准点的平均角度距离 |
| RMS precision | 区分“位置偏”与“点一直抖” | 稳定校准点期间相邻样本位移的 RMS |
| Data loss | 丢失会改变热图，也会造成选择偏倚 | 无效样本 / 应有样本 |
| Valid-trial share | 防止只看幸存试次的漂亮均值 | 有效试次 / 应有试次 |

为什么不能只看 p 值：500+500 时，很小且不重要的差异也容易显著；反过来，“没有显著差异”也不能证明足够相似。

正确做法是先由研究团队为每个用途规定可接受差异，比如准确度最多差多少度、丢失率最多差多少。然后计算独立样本 Welch 90% 置信区间：

- 整个区间在容许范围内：支持“在该指标上足够相似”；
- 整个区间超出范围：存在实质差异；
- 其他情况：证据不足，不能硬判。

对应图：`02_quality_equivalence.png` 和 `03_quality_distributions.png`。

### 第三步：用“同一队列自己能有多稳定”作为热图基线

不要要求两组热图达到 1.00，因为即使把同一来源的 500 人随机分成两半，两张热图也不会完全一样。

每张刺激图重复做：

1. 把 500 个 Webcam 人随机分成 250/250，算两半热图相似度；
2. 把 500 个专业设备参与者随机分成 250/250，算两半相似度；
3. 拿 Webcam 的一半与专业设备的一半比较；
4. 重复几百次。

主指标用 SIM（Histogram Intersection），范围 0–1，表示两张标准化热图共享多少密度。然后问：跨域 SIM 比较差的那个组内 SIM 低了多少？这个损失是否超过事先规定的容许值？

对应图：

- `04_group_attention_maps.png`：专业、Webcam、带正负号的差值热图；
- `05_map_reproducibility.png`：组内拆半基线与跨域相似度；
- `06_aoi_profile.png`：眼睛、鼻子、嘴唇和其他区域的 dwell share。

AOI 好理解，但它是次要指标：一个大眼睛框内部发生偏移，AOI 比例可能看不出来，所以仍要保留整张差值图。

### 第四步：用简单来源分类器检查“域差异”

用 Logistic Regression 做重复五折交叉验证，分别运行：

- 技术质量特征模型；
- 注意力模式特征模型。

看 AUC：

- 0.50 左右：这个简单模型难以识别来源；
- 越接近 1.00：两个域越容易区分。

但必须避免把 site、Prolific/Mayo 标签这类一眼暴露来源的字段放进去。低 AUC 也不能证明两个总体完全相同，它只说明当前特征和模型没有分开。

对应图：`07_domain_classifier.png`。

## 最终应该怎样写结论

合适：

> 在相同版本刺激和本研究协议下，Webcam 500 人群体热图相对于两队列各自拆半重复性的损失，没有超过预先规定的 SIM 容许值；该证据支持把 Webcam 用于这一特定的群体注意力图用途。

不合适：

- “两台设备一样好”；
- “两个域完全一样”；
- “Webcam 可以替代专业设备测量个人”；
- “差异不显著，所以等效”；
- “样本量都是 500，所以没有偏倚”。

## 真实数据到来后最先需要的字段

1. 匿名 participant ID 和 cohort；
2. stimulus/task/transform/AOI/QC version；
3. 校准 target 与参与者级准确度、precision；
4. expected/valid sample 和 trial 计数；
5. 统一坐标下的 gaze 或 device-neutral fixation/dwell；
6. 年龄段、眼镜等合理参与者变量；
7. 屏幕、光线、浏览器、相机/追踪器、软件与算法版本。

如果两组看的脸部图片不是完全相同，注意力热图主分析只能限制到共同刺激；没有共同刺激就不能把热图差异解释为设备或采集流程差异。

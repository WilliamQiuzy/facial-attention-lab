FaceAI — Start Here
===================

This ZIP contains the complete FaceAI website, including Patients, Review,
Help, photo capture, and the pre-operative/post-operative workflow. It is not
a single-file HTML demo.

Before opening FaceAI
---------------------
Install Node.js 22 LTS or newer from https://nodejs.org/en/download if it is
not already installed.

Mac
---
1. Double-click START-FACEAI-MAC.command.
2. If macOS shows a security warning, right-click the file, choose Open, and
   confirm Open.
3. Keep the Terminal window open while using FaceAI.

Windows
-------
1. Double-click START-FACEAI-WINDOWS.bat.
2. Keep the command window open while using FaceAI.

The default browser opens automatically at a localhost address. Allow camera
access when prompted. Closing the Terminal or command window stops FaceAI.

This package is a research prototype for sample or de-identified information.
It does not include a clinical attention model or a patient-data backend.

# Archived Web-Model Autoresearch Harness

This directory is retained only to reproduce the pre-Universal-v4 web benchmark.
It is not a supported training or inference entrypoint. Bulk candidate JSON/TSV
files, logs, and derived model products were removed from the active tree; Git
history preserves them if a historical audit is required.

New model work starts from `src.models.current` and the artifact registered in
`docs/model_registry.json`.

# 医生材料中文规范

本规范适用于提供给中国医生阅读的界面、模型说明、结果摘要、导出报告和汇报材料。

## 强制要求

1. 医生可见正文必须使用中文。
2. 不得出现未解释的英文缩写、英文指标名或英文架构名。
3. 数据集、模型和工具的原始名称只在确有必要时出现一次，并放入“技术备注”或“名称对照”，正文继续使用简短中文名称。
4. 代码标识、文件路径、机器字段和哈希值不翻译，但只能放在技术备注或开发者材料中。
5. 指标第一次出现时必须用一句中文说明它测试什么，之后使用固定的简短中文名称。
6. 医生材料不得把开发集结果写成临床验证，也不得把只有阳性病例时的阳性调用率写成二分类正确率。

## 推荐用词

| 推荐中文 | 含义 |
|---|---|
| 排序能力 | 模型把受影响者排在未受影响者之前的能力 |
| 正确率 | 在固定判断规则下，判断正确的人数比例 |
| 类别平衡正确率 | 受影响者检出率与未受影响者排除率的平均值 |
| 检出率 | 受影响者被正确检出的比例 |
| 排除率 | 未受影响者被正确排除的比例 |
| 概率误差 | 预测概率与实际结果之间的误差，越低越好 |
| 把握度 | 模型对当前判断的确定程度 |
| 暂不判断 | 证据不足时不强行给出阳性或阴性结论 |

## 文档结构

医生材料先给结论、适用范围和限制，再给结果表格与中文名词说明。必须保留的模型名、数据名、代码标识和文件路径统一放在文末“技术备注”中，不在正文反复出现。
